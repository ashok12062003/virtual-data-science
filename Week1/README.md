# Week 1: Python for Machine Learning & Data Preprocessing

## Project Overview

This project is part of my remote technical internship. The objective is to understand Python fundamentals for machine learning and implement essential data preprocessing techniques using Python libraries.

The project uses an existing CSV dataset to demonstrate data inspection, data cleaning, missing-value handling, duplicate removal, categorical encoding, numerical normalization, and exploratory data analysis (EDA).

## Objectives

- Understand Python fundamentals for machine learning.
- Load and inspect CSV datasets using Pandas.
- Perform numerical operations using NumPy.
- Identify and handle missing values.
- Remove duplicate records.
- Encode categorical variables.
- Normalize numerical features.
- Perform exploratory data analysis and generate visualizations.
- Save the processed dataset for further analysis.

## Implementation

### 1. Dataset Inspection

The dataset is loaded from a CSV file. Its dimensions, column names, data types, first few rows, descriptive statistics, and missing-value counts are examined.

### 2. Data Cleaning

- Identify missing values.
- Remove duplicate records.
- Fill missing numerical values using median imputation.
- Fill missing categorical values using mode imputation.
- Save the cleaned dataset separately.

### 3. Feature Engineering

- Convert categorical variables into numerical representations.
- Normalize numerical features using Min-Max scaling.
- Save the engineered dataset for further analysis.

### 4. Exploratory Data Analysis

- Examine dataset dimensions and descriptive statistics.
- Check missing values.
- Generate numerical feature distribution histograms.
- Generate a correlation heatmap where applicable.
- Save visualizations in the screenshots folder.

## Installation

Install Python and ensure it is available in your terminal.

Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

The `requirements.txt` file should contain:

```text
numpy
pandas
scikit-learn
matplotlib
```

## How to Run

Open the project folder in Visual Studio Code and run the scripts from the Week1 directory.

Run data preprocessing:

```bash
python src/preprocessing.py
```

Run feature engineering:

```bash
python src/feature_engineering.py
```

Run exploratory data analysis:

```bash
python src/eda.py
```

## Expected Outputs

The project generates:
